# 🌮 Taco Bell Website Clone

A responsive **Taco Bell website recreation** built using HTML, CSS, JavaScript, and Bootstrap. This project focuses on recreating the visual design, layout, navigation, menu sections, and interactive elements of a modern restaurant website.

## 🚀 Live Demo

🔗 [https://tacobellrecreation.netlify.app/](url)

## 📌 About the Project

This project was created as a frontend development practice project to strengthen my skills in building responsive and interactive websites.

The website recreates the look and feel of the Taco Bell website while implementing the interface from scratch using frontend technologies.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Custom styling and responsive design
- **JavaScript** – Interactive functionality
- **Bootstrap** – Responsive layouts and UI components

## ✨ Features

- Responsive website design
- Navigation bar and menu sections
- Restaurant/product showcase
- Interactive buttons and UI elements
- Responsive Bootstrap components
- Mobile-friendly layout
- Custom CSS styling
- JavaScript-based interactions

## 🎯 Purpose

The goal of this project was to practice:

- Building responsive layouts
- Working with Bootstrap
- Writing clean HTML and CSS
- Adding JavaScript interactions
- Recreating a real-world website interface
- Deploying a frontend project using GitHub and Netlify

## 🌐 Deployment

This project is deployed using **Netlify** and connected to the GitHub repository for continuous deployment.

Any changes pushed to the connected GitHub branch can automatically trigger a new deployment.

## ⚠️ Disclaimer

This project is a **frontend recreation made for educational and portfolio purposes**. It is not affiliated with or officially connected to Taco Bell.
